# Moeda Capitolina 🪙

**Moeda Capitolina** é o componente digital do jogo de tabuleiro phygital **O Dilema de Casmurro**. Este aplicativo atua como o motor de sorte (RNG) para decisões cruciais durante a partida, unindo a imersão da literatura machadiana com a tecnologia móvel.

## 🎭 O Dilema de Casmurro
Inspirado na obra *Dom Casmurro*, de Machado de Assis, o jogo coloca os jogadores frente ao eterno impasse entre a dúvida e a certeza. A Moeda Capitolina é utilizada sempre que o tabuleiro ou as cartas de evento exigem um veredito da sorte.

## ✨ Funcionalidades
- **Física de Lançamento:** Animação de flip 3D com simulação de altura e queda.
- **Feedback Háptico:** Vibração sincronizada com o impacto da moeda na "mesa".
- **Estética Sombria:** Interface inspirada no luxo decadente do século XIX.
- **Offline First:** Funciona sem necessidade de conexão com a internet, ideal para sessões de jogo em qualquer lugar.

## 🛠️ Tecnologias
- **Linguagem:** Kotlin
- **Plataforma:** Android Nativo
- **IDE:** Android Studio

## 📥 Instalação
Para instalar o aplicativo no seu dispositivo Android:
1. Vá até a seção [Releases](https://github.com/kaue-sito/moeda-capitolina/releases).
2. Baixe o arquivo `.apk` da versão mais recente.
3. No seu celular, permita a instalação de fontes desconhecidas e execute o arquivo.
